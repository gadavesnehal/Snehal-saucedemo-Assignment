#Steps to set up and Run the project:

1.Create any folder in your Computer system

2.Open that folder in Visual Studio Code

3.Click on Terminal menu at the top and open New Terminal

4.Clone the repository using below command -

git clone https://github.com/gadavesnehal/Snehal-saucedemo-Assignment.git

5.Navigate to the repository folder using the below command -

cd Snehal-saucedemo-Assignment

6.Commands to Run Cypress Automation Test Cases -

To open the Cypress Test Runner, use the following command:

npx cypress open

Once executed, a new Cypress window will open.

a) Select "E2E Testing".
b) Select the "Chrome" browser.
d) Click "Start E2E Testing in Chrome" to begin running your test cases.
